# KASANE / かさね

架空のアパレルブランドのコーポレートサイト。**Web 表現のデモンストレーションであり、実在の企業・店舗・商品とは関係がありません。**

→ https://makoto0808ellhome-ui.github.io/kasane/

## これは何か

スクロールに紐づいて動くコーポレートサイトを、架空のアパレルブランドを題材に一式組んだもの。

ブランド名の由来は「襲の色目（かさねのいろめ）」。平安の装束で、重ねた衣の端にだけ色が覗く配色法を指す。
これにより「モノトーンに一色だけ差す」というアートディレクションが、そのままブランドの由来と一致する。

| 役割 | 名 | 値 |
|---|---|---|
| 地 | 墨 | `#14110F` |
| 抜き | 生成り | `#EFEAE1` |
| 差し色 | 洗朱 | `#C9442B` |

## 作り

ビルド不要のバニラ HTML / CSS / JS。依存パッケージはゼロ。

- `index.html` — 本文
- `styles.css` — 全スタイル
- `script.js` — スクロール連動、円マスク遷移、横スクロール、幕
- `gl.js` — 背景の布。**three.js を使わず WebGL2 を直書き**（約 12KB）
- `assets/` — 写真（`.webp` を配信、`.jpg` をフォールバック）

背景は一枚の布を吊るして揺らしている。上辺はピン留めで振幅ゼロ、下へ行くほど大きく振れる。
経糸を左右に寄せて粗密をつくることで、格子ではなく布に見せている。

### 段階的な縮退

1. WebGL2 が無い → 2D canvas の静止した織り目
2. `prefers-reduced-motion: reduce` → 演出が静止し、横スクロールは素直なスクロールバーに落ちる
3. JavaScript が無効 → 全文がそのまま読める

検証用に `?motion=force`（動きを押し切る）と `?motion=reduce`（動きを止める）を受け付ける。

## ローカルで見る

依存が無いので、静的に配れれば何でもよい。

```
python -m http.server 8000
```
